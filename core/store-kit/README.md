# @crossbind/core-store-kit

What crossbind's publishers share for app stores: reading a store listing's language folders, its files and images,
asking for the app's id through the extension `api`, and App Store Connect's API, the app's versions, their review and the
listing in `store/app-store`, which the iOS app's and the Mac App Store's publishers share. It imports nothing of
crossbind's.
