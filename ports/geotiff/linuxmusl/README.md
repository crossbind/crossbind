# @crossbind/port-geotiff-linuxmusl

The **Linux (musl)** build of the precompiled **libgeotiff** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-geotiff](https://www.npmjs.com/package/@crossbind/port-geotiff)**.

## Supported targets
- Linux (musl) — `x64` (x86_64)
- Linux (musl) — `arm64` (aarch64)

Requires musl 1.2.5 or later, as on Alpine Linux 3.21 and later.
