# @crossbind/port-geotiff-darwin

The **macOS** build of the precompiled **libgeotiff** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-geotiff](https://www.npmjs.com/package/@crossbind/port-geotiff)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
