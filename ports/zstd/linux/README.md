# @crossbind/port-zstd-linux

The **Linux** build of the precompiled **zstd** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-zstd](https://www.npmjs.com/package/@crossbind/port-zstd)**.

## Supported targets
- Linux — `x64` (x86_64)
- Linux — `arm64` (aarch64)

Requires glibc 2.28 or later, the baseline of Node.js's own Linux builds.
