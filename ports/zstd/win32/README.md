# @crossbind/port-zstd-win32

The **Windows** build of the precompiled **zstd** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-zstd](https://www.npmjs.com/package/@crossbind/port-zstd)**.

## Supported targets
- Windows — `x64`
- Windows — `arm64`

Requires Windows 10 or later, whose Universal CRT the binaries use.
