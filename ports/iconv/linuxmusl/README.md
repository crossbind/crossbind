# @crossbind/port-iconv-linuxmusl

The **Linux (musl)** build of the precompiled **libiconv** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-iconv](https://www.npmjs.com/package/@crossbind/port-iconv)**.

## Supported targets
- Linux (musl) — `x64` (x86_64)
- Linux (musl) — `arm64` (aarch64)

Requires musl 1.2.5 or later, as on Alpine Linux 3.21 and later.
