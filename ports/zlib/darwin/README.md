# @crossbind/port-zlib-darwin

The **macOS** build of the precompiled **zlib** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-zlib](https://www.npmjs.com/package/@crossbind/port-zlib)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
