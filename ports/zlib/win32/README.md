# @crossbind/port-zlib-win32

The **Windows** build of the precompiled **zlib** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-zlib](https://www.npmjs.com/package/@crossbind/port-zlib)**.

## Supported targets
- Windows — `x64`
- Windows — `arm64`

Requires Windows 10 or later, whose Universal CRT the binaries use.
