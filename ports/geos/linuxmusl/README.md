# @crossbind/port-geos-linuxmusl

The **Linux (musl)** build of the precompiled **GEOS** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-geos](https://www.npmjs.com/package/@crossbind/port-geos)**.

## Supported targets
- Linux (musl) — `x64` (x86_64)
- Linux (musl) — `arm64` (aarch64)

Requires musl 1.2.5 or later, as on Alpine Linux 3.21 and later.
