# @crossbind/port-geos-darwin

The **macOS** build of the precompiled **GEOS** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-geos](https://www.npmjs.com/package/@crossbind/port-geos)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
