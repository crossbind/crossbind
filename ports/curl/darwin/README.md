# @crossbind/port-curl-darwin

The **macOS** build of the precompiled **libcurl** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-curl](https://www.npmjs.com/package/@crossbind/port-curl)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
