# @crossbind/port-webp-darwin

The **macOS** build of the precompiled **WebP** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-webp](https://www.npmjs.com/package/@crossbind/port-webp)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
