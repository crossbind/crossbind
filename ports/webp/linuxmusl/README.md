# @crossbind/port-webp-linuxmusl

The **Linux (musl)** build of the precompiled **WebP** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-webp](https://www.npmjs.com/package/@crossbind/port-webp)**.

## Supported targets
- Linux (musl) — `x64` (x86_64)
- Linux (musl) — `arm64` (aarch64)

Requires musl 1.2.5 or later, as on Alpine Linux 3.21 and later.
