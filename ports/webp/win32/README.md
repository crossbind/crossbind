# @crossbind/port-webp-win32

The **Windows** build of the precompiled **WebP** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-webp](https://www.npmjs.com/package/@crossbind/port-webp)**.

## Supported targets
- Windows — `x64`
- Windows — `arm64`

Requires Windows 10 or later, whose Universal CRT the binaries use.
