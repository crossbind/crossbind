# @crossbind/port-jpegturbo-darwin

The **macOS** build of the precompiled **libjpeg-turbo** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-jpegturbo](https://www.npmjs.com/package/@crossbind/port-jpegturbo)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
