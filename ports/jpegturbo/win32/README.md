# @crossbind/port-jpegturbo-win32

The **Windows** build of the precompiled **libjpeg-turbo** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-jpegturbo](https://www.npmjs.com/package/@crossbind/port-jpegturbo)**.

## Supported targets
- Windows — `x64`
- Windows — `arm64`

Requires Windows 10 or later, whose Universal CRT the binaries use.
