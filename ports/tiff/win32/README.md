# @crossbind/port-tiff-win32

The **Windows** build of the precompiled **TIFF** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-tiff](https://www.npmjs.com/package/@crossbind/port-tiff)**.

## Supported targets
- Windows — `x64`
- Windows — `arm64`

Requires Windows 10 or later, whose Universal CRT the binaries use.
