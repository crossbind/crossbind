# @crossbind/port-tiff-linux

The **Linux** build of the precompiled **TIFF** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-tiff](https://www.npmjs.com/package/@crossbind/port-tiff)**.

## Supported targets
- Linux — `x64` (x86_64)
- Linux — `arm64` (aarch64)

Requires glibc 2.28 or later, the baseline of Node.js's own Linux builds.
