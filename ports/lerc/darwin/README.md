# @crossbind/port-lerc-darwin

The **macOS** build of the precompiled **LERC** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-lerc](https://www.npmjs.com/package/@crossbind/port-lerc)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
