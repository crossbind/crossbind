# @crossbind/port-gdal-darwin

The **macOS** build of the precompiled **GDAL** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-gdal](https://www.npmjs.com/package/@crossbind/port-gdal)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
