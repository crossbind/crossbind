# @crossbind/port-spatialite-darwin

The **macOS** build of the precompiled **SpatiaLite** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-spatialite](https://www.npmjs.com/package/@crossbind/port-spatialite)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
