# @crossbind/port-spatialite-linux

The **Linux** build of the precompiled **SpatiaLite** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-spatialite](https://www.npmjs.com/package/@crossbind/port-spatialite)**.

## Supported targets
- Linux — `x64` (x86_64)
- Linux — `arm64` (aarch64)

Requires glibc 2.28 or later, the baseline of Node.js's own Linux builds.
