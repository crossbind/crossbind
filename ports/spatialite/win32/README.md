# @crossbind/port-spatialite-win32

The **Windows** build of the precompiled **SpatiaLite** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-spatialite](https://www.npmjs.com/package/@crossbind/port-spatialite)**.

## Supported targets
- Windows — `x64`
- Windows — `arm64`

Requires Windows 10 or later, whose Universal CRT the binaries use.
