# @crossbind/port-openssl-darwin

The **macOS** build of the precompiled **OpenSSL** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-openssl](https://www.npmjs.com/package/@crossbind/port-openssl)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
