# @crossbind/port-openssl-linux

The **Linux** build of the precompiled **OpenSSL** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-openssl](https://www.npmjs.com/package/@crossbind/port-openssl)**.

## Supported targets
- Linux — `x64` (x86_64)
- Linux — `arm64` (aarch64)

Requires glibc 2.28 or later, the baseline of Node.js's own Linux builds.
