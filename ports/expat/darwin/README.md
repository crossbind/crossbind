# @crossbind/port-expat-darwin

The **macOS** build of the precompiled **Expat** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-expat](https://www.npmjs.com/package/@crossbind/port-expat)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
