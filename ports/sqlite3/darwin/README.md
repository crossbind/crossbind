# @crossbind/port-sqlite3-darwin

The **macOS** build of the precompiled **SQLite3** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-sqlite3](https://www.npmjs.com/package/@crossbind/port-sqlite3)**.

## Supported targets
- macOS — `arm64` (Apple silicon)
- macOS — `x64` (Intel)

Requires macOS 11 or later.
