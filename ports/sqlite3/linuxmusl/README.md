# @crossbind/port-sqlite3-linuxmusl

The **Linux (musl)** build of the precompiled **SQLite3** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-sqlite3](https://www.npmjs.com/package/@crossbind/port-sqlite3)**.

## Supported targets
- Linux (musl) — `x64` (x86_64)
- Linux (musl) — `arm64` (aarch64)

Requires musl 1.2.5 or later, as on Alpine Linux 3.21 and later.
