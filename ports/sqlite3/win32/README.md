# @crossbind/port-sqlite3-win32

The **Windows** build of the precompiled **SQLite3** library, built with [crossbind](https://crossbind.dev).

> For installation and usage, see the main package: **[@crossbind/port-sqlite3](https://www.npmjs.com/package/@crossbind/port-sqlite3)**.

## Supported targets
- Windows — `x64`
- Windows — `arm64`

Requires Windows 10 or later, whose Universal CRT the binaries use.
