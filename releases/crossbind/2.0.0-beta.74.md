## Highlights

### Open-source licenses for a page and its app

- `licenses()` from `crossbind/licenses` resolves to `{ name, version, license, source, text }[]`, for a screen of
  open-source licenses in an app or on a web page.
- In a build of a page that imports it, the Vite and Rollup plugins write `crossbind-licenses.json` beside the page: the
  libraries the module links and the copies they vendor, what an app's host carries, and every npm package whose modules
  or files the page's bundle holds, but for the project's own package and private ones. An app carries the file in
  `page/`. A page that does not import `crossbind/licenses` gets no file.
- The dev server has no list, so there `licenses()` rejects, saying so.

```js
import { licenses } from 'crossbind/licenses';

for (const { name, version, license, source, text } of await licenses()) {
    // license is an SPDX expression; text holds the component's license files, or is null
}
```

Reference: `docs/api/app.md`.

### Notices and SBOMs

- Notices and SBOM components name each library's upstream project, with its CPE in the SBOM, as the ports now declare
  it in `crossbind.upstream.name` and `cpe`: `zlib`, `libjpeg-turbo`, `libtiff` and `sqlite` in place of `z`, `jpeg`,
  `tiff` and `sqlite3`. The rows of crossbind's runtime carry their versions.
- `--platform wasm` lists crossbind's runtime, which the module's glue bundles, beside Emscripten's libraries and LLVM's
  C++ runtime.
- The relinking steps of a published package link the tag the new `licenses.sourceTag` option names, `{name}@{version}`
  unless the project sets another, and the override playbook by its URL, and build the packages the artifact links
  first. A wasm module's notices carry them too.
- A Node-API package without an addon covers the runtime, the project's code and the data it ships, and an umbrella
  package's `LICENSE` says each platform package carries the `LICENSE` of its addon.
- This release publishes every crossbind package again, so the `LICENSE` and `sbom.cdx.json` of the standalone Node-API
  and WASI packages carry the above. The `license` field of each umbrella package, as
  `@crossbind/port-geos-standalone-napi`, now names what it ships, the bindings, types and data: `(MIT OR NCSA) AND MIT`
  for most families. The library's own license stays in the platform package that holds the addon, as
  `@crossbind/port-geos-standalone-napi-linux-x64`.

Reference: `docs/playbooks/licensing-lgpl.md`, `docs/api/crossbind-config.md`.

### GDAL

- Every `@crossbind/port-gdal-*` package builds GDAL's planetary formats: PDS, PDS4, ISIS2, ISIS3 and VICAR, and OGR's
  PDS tables. The port had turned them off.

## Breaking changes

None.

## Migration notes

- Upgrade the crossbind packages a project uses to `2.0.0-beta.74` together, its plugins, extensions and ports
  included: the plugins write the license list with this `crossbind`, and the ports' family packages carry the upstream
  names and CPEs its notices and SBOM take.
- A tool that reads `crossbind licenses` output by component name finds `zlib`, `libjpeg-turbo`, `libtiff` and `sqlite`
  where it found `z`, `jpeg`, `tiff` and `sqlite3`, and purls to match, as `pkg:generic/zlib@1.4`.
- A license check that reads the `license` field of `@crossbind/port-geos-standalone-napi` finds `LGPL-2.1-only` in
  the platform package npm installs beside it, as `@crossbind/port-geos-standalone-napi-linux-x64`, and no longer in the
  umbrella package; the same holds for every family.
- TypeScript code that cast what `initNative()` resolves to can drop the cast.

## Fixes

- `initNative()` resolves to a `NativeModule` that names the bound classes and the module's `toVector` and `toArray`,
  with an index signature for what only some runtimes have, as `FS` in a wasm build; the declarations typed it as a
  promise of `unknown`.
- A header edit that leaves its bridge's text as it was, as a new signature for a bound function can, rebuilds the
  bridge library. The library built from the old header was kept, and the module failed to link on the old symbol until
  the build folder was cleared by hand.
- When a project lists a library's packages for several platforms, `crossbind licenses` takes the one of the platform it
  lists, and a project whose alias names another package gets that package's license.
- `--notices` and `--sbom` without `--platform` warn when a library vendors copies, which only a platform's listing
  holds.

## Known limitations

- `crossbind-licenses.json` leaves out a file a stylesheet inlines, under Vite's 4 KB `assetsInlineLimit`, and worker
  bundles; the webpack and Metro plugins do not write it; Emscripten's and LLVM's rows have no license text, as their
  notices give only a URL.
- Conan packages come from ConanCenter only and have no WASI builds. An option a recipe gives no default and drops
  for a target is read as one the recipe does not have.
- The Node.js wasm `fsync` workaround reaches the operating system but does not force data to disk.
- The Windows NSIS installer downloads WebView2 when it is missing, so the Microsoft Store does
  not accept that installer.
- The Android app image's Gradle and Android build tools still carry the Guava issue tracked in
  `docs/known-issues.md`, under the existing scan exception until 15 December 2026.
