## Integration
To integrate crossbind into your project using React Native or Expo, you can utilize the @crossbind/plugin-react-native-ios-helper plugin. Start by installing these package with the following command:

NPM
```sh
npm install @crossbind/plugin-react-native-ios-helper@beta --save-dev
```
or YARN
```sh
yarn add @crossbind/plugin-react-native-ios-helper@beta --dev
```
or PNPM
```sh
pnpm add @crossbind/plugin-react-native-ios-helper@beta --save-dev
```
or BUN
```sh
bun add @crossbind/plugin-react-native-ios-helper --dev
```
